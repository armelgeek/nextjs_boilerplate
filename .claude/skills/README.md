# Project Skills

Custom skills for this solo builder project. These enhance Claude Code workflows.

## Available Skills

### 1. idea-clarifier
**Purpose:** Turn vague ideas into clear, implementation-ready specifications.

**Trigger:**
```
/idea-clarifier
```

**What it does:**
- Asks focused questions to understand your product
- Generates complete spec in `docs/product/` folder (14 markdown files):
  - Product brief & goals
  - User roles & journeys
  - MVP scope (must/should/could have)
  - Functional requirements
  - Business rules
  - Data model
  - Technical architecture
  - Development roadmap
  - Risks & open questions

**When to use:**
- Starting a new project or major feature
- Idea is still vague
- Need clear specification before coding

**Output:** `docs/product/` folder with complete documentation

---

### 2. project-manager
**Purpose:** Convert product specs into weekly development plans.

**Prerequisite:** Run `/idea-clarifier` first to generate `docs/product/`

**Trigger:**
```
/project-manager
```

**What it does:**
- Reads `docs/product/` (generated by idea-clarifier)
- Extracts MVP scope, user journeys, requirements
- Creates weekly sprint plan
- Estimates effort per phase
- Maps features to sustainable pace (4-5 hours/day)

**When to use:**
- After running idea-clarifier
- Starting implementation
- Weekly review & replanning

**Output:** Development roadmap for 4-6 weeks

---

## Typical Workflow

```
1. Start new project
   ↓
   /idea-clarifier
   (generates docs/product/)
   ↓
   Validate spec with team/yourself
   ↓
   
2. Plan implementation
   ↓
   /project-manager
   (reads docs/product/, creates plan)
   ↓
   Execute weekly sprints
   ↓
   
3. Every Friday
   ↓
   Review progress
   Update docs/product/ if needed
   /project-manager (replan next weeks)
   ↓
   Continue or pivot
```

## Skill Location

Skills are stored in:
```
.claude/agents/skills/
├── idea-clarifier/
│   └── SKILL.md
├── project-manager/
│   └── SKILL.md
└── README.md (this file)
```

Claude Code automatically discovers skills in this directory. Just type `/skill-name` to invoke.

---

## How Claude Code Finds Skills

1. **Local Skills First** (highest priority)
   - Checks `.claude/agents/skills/` (this directory)
   - Your custom project skills live here

2. **Public Skills** (medium priority)
   - Checks `.claude/skills/` (shared skills)

3. **Plugins** (lowest priority)
   - Checks `.claude/plugins/` (installed plugins like superpowers)

**Your skills always override public/plugin skills.**

- `.claude/CLAUDE.md` (project guidelines)

## Key Points

✅ **idea-clarifier generates the spec** (source of truth)
✅ **project-manager reads the spec and creates the plan**
✅ **Your code implements the plan**
✅ **Weekly sync keeps everything aligned**

## Adding More Skills

To add a new skill:

1. Create folder: `.claude/agents/skills/new-skill/`
2. Create file: `new-skill/SKILL.md`
3. Follow SKILL.md format (see existing skills)
4. Claude Code will find it automatically

```bash
mkdir -p .claude/agents/skills/new-skill
touch .claude/agents/skills/new-skill/SKILL.md
```

Then use: `/new-skill`
